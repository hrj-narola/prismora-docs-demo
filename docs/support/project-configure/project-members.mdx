# Project Members

The **Project Members** module allows project owners to collaborate effectively by inviting team members to their projects and assigning them specific access roles. This ensures secure and managed access to project resources.

## Inviting Members

Project Owners can invite new members to a project directly via email:

1. Navigate to the **Project Members** tab within your project configuration page.
2. Click on the **Invite Member** button.
3. Enter the **Email Address** of the person you wish to invite.
4. Select an appropriate **Role** for the invitee to define their access level. Currently, the available roles are:
   - **Admin**: Full access to manage project resources, configurations, test executions and same access like owner.
   - **Member**: Standard access to contribute to the project and execute tasks.
   - **Viewer**: Read-only access to view project details without the ability to make changes or execution test runs.

## Receiving an Invitation

Once an invitation is sent, the experience differs slightly depending on whether the invitee already has an account on the platform:

### For Existing Users
If the invited member already has an active account:
1. They will receive an invitation notification via email.
2. They can simply log in to the platform using their existing credentials.
3. Once logged in, they will see the pending invitation and can choose to **Accept** or **Decline** it.

### For New Users
If the invited member does not yet have an account:
1. They will receive an email containing an exclusive **invite link**.
2. Clicking this link will direct them to a setup page where they can securely **Set a Password** for their new account.
3. After creating their password, they can log in to the platform and will automatically be granted access to the project.

## Accessing the Project

After successfully accepting the invitation or completing the signup process, the member will be able to access the project. Their permissions and available actions within the project will be strictly governed by the **Role** assigned to them during the invitation.
